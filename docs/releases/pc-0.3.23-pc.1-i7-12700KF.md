**WSword for PC, built for one CPU: the Intel Core i7-12700KF** (12th gen; it runs on that and newer Intel CPUs like it). Built on **[Savage Wind Recomp](https://github.com/Revivedx/SavageWindRecomp) 0.4.1-alpha.4** (MIT). For everyone else: use the normal releases.

No game files are included. You need your own dump of *Breath of the Wild* **1.9.0** (recommended) or 1.8.2.

### amiibo: every figure, from a bar in the game

- **Use the amiibo rune** (turn on *amiibo* in the game's options first; it's under Gameplay again). While the game looks for a figure, the **amiibo bar** comes up across the screen, in the look of the game's weapon and rune bars.
- **Pick** with the d-pad left/right or the right stick; d-pad down/up jumps to the next/previous series. **A** taps the figure; the game finds it as if it were on the reader. **B** leaves the rune as usual.
- **X** stars a figure: favourites come first in the bar. Breath of the Wild's own figures (Wolf Link, the Champions, Guardian, ...) follow, then the rest of the Zelda series, then every other amiibo — 932 in all.
- **Once a day:** the game's own rule (one drop per figure per day) is kept by default. Turn off *One scan a day per figure* in the menu's About tab to tap the same figure again straight away.
- Each figure keeps its own saved data (Wolf Link's hearts, for one) in `amiibo/` next to WSword.

Virtual amiibo only: the list is just the figures' public ids and names (from [AmiiboAPI](https://github.com/N3evin/AmiiboAPI), MIT) — no figure's dump, no keys, no artwork.

### Updating

Unzip `WSword-0.3.23-pc.1-i7-12700KF-windows.zip` **over your WSword folder** and replace the files. Everything else stays as it is, and the PC's game code isn't built again.

The PS5 version is WSwordPS5 v0.3.26-m4.

Made without testing in the game.
